# DebugMate 프론트엔드 전역 규칙

## 1. 공통 구조

모든 페이지는 `공통 헤더 → 본문 → 공통 푸터` 순서를 사용합니다. 헤더와 푸터는 `templates/fragments/layout.html`에서 한 번만 관리합니다. 본문 폭은 최대 1120px이며, 입력과 상세 페이지는 860px로 제한합니다.

## 2. 디자인 토큰

색상, 글꼴, 모서리, 그림자와 본문 폭은 `static/css/app.css`의 `:root` 변수만 사용합니다. 새로운 색이나 간격 값을 페이지마다 임의로 만들지 않습니다.

- 기본 배경: `#f5f7fb`
- 기본 글자: `#162033`
- 핵심 색상: `#4856e8`
- 강조 색상: `#82e6c2`
- 성공: 초록, 검토 필요: 주황, 오류: 빨강
- 기본 모서리: 8px, 14px, 24px의 세 단계

## 3. 타이포그래피

본문은 시스템 한글 글꼴을 사용하고 코드는 고정폭 글꼴을 사용합니다. 한 페이지에는 `h1`을 하나만 둡니다. 제목 아래 설명은 회색으로 표시하고, 영문 눈썹 제목은 섹션 구분에만 사용합니다.

## 4. 내비게이션

모든 페이지에서 같은 메뉴 순서를 유지합니다. 현재 페이지는 핵심 색상과 옅은 배경으로 표시합니다. 로고를 누르면 항상 대시보드로 이동합니다.

## 5. 버튼

- 핵심 행동은 `.button.primary`를 사용합니다.
- 취소, 검색, 보조 이동은 `.button.secondary`를 사용합니다.
- 한 화면의 주요 버튼은 가능한 한 하나만 둡니다.
- 사용할 수 없는 기능은 숨기지 않고 `.button.disabled`로 표시해 개발 범위를 명확히 보여줍니다.

## 6. 입력 폼

모든 입력에는 화면에 보이는 `label`이 필요합니다. 필수 항목에는 `필수`를 표시합니다. 코드와 오류 로그는 고정폭 글꼴을 사용합니다. 오류 메시지는 입력 바로 아래에 빨간색으로 표시합니다.

## 7. 상태 표시

상태 이름과 색을 모든 페이지에서 동일하게 사용합니다.

- 분석 대기: 보라색
- 해결 완료: 초록색
- 검토 필요: 주황색

색상만으로 상태를 전달하지 않고 반드시 텍스트를 함께 표시합니다.

## 8. 반응형과 접근성

760px 이하에서는 2열 화면을 1열로 변경합니다. 모든 기능은 키보드로 사용할 수 있어야 하며, 본문 바로가기 링크와 의미 있는 HTML 요소를 유지합니다. 명도 대비가 낮은 글자는 핵심 정보에 사용하지 않습니다.

## 9. AI 기능 표시 원칙

AI가 연결되기 전에는 가짜 분석 결과를 만들지 않습니다. 비활성 버튼과 안내 문구로 기능의 예정 위치만 보여줍니다. 향후 연동하더라도 AI 결과는 `원인`, `수정안`, `설명`, `검증 절차`로 구분합니다.
